## Thinking
* Idea of Lanes just came to me. There are 8 tracks but if you moved to a DAW you would be considering tracks based on when a track contains a new or diverged (merged tracks) idea. It will help with organization if it's broken down this way. For example, you might have percussion in one track, mute it for awhile, and then put a synth into that track next. In a DAW you would want each of those ideas in a sepererate track.
	* Lane might not be the best fit. It's basically the thing you get when you stitch together a number of rifffs (if you're building a percussion track for example).

## Functions
* When you're editing a hop, the initial or main view would be where you see stacked or overlayed where the hop point is. For fine adjustments, like to move the point to the start of when a sound comes in, you would just drag the hop point. You'd need to see all the tracks stacked to see where sounds are coming in and exiting.
* If you want to change the hop point drastically, you need to either expand the space between two hop points (undoing the collapse a hop produces) or expand the space before or after a hop point if you want to have it happen earlier or later. In expansion, you would want to see each rifff in full and then audition/pick where the new point should be before collapsing again.
